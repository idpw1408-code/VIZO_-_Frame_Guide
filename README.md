# Aspect Ratio Master

[English]
Aspect Ratio Master is a lightweight PWA (Progressive Web App) designed to calculate image dimensions based on aspect ratios. It helps users quickly find the perfect width and height for their creative projects without needing to install heavy software.

[한국어]
Aspect Ratio Master는 종횡비를 기반으로 이미지의 가로/세로 크기를 계산해주는 가벼운 PWA(웹 앱)입니다. 무거운 소프트웨어를 설치할 필요 없이, 웹에서 즉시 작업에 필요한 최적의 해상도를 계산할 수 있습니다.

## Features / 주요 기능
- **Real-time Calculation**: Instant results as you type. / 실시간 자동 계산.
- **Customizable**: Supports various presets and custom aspect ratios. / 다양한 프리셋 및 사용자 정의 종횡비 지원.
- **PWA Ready**: Installable as a native app on both mobile and desktop. / 모바일 및 데스크톱에서 기본 앱으로 설치 가능.

## How to Install / 설치 방법
1. Visit the project website: [https://idpw1408-code.github.io/AR_Master/](https://idpw1408-code.github.io/AR_Master/)
2. **Desktop**: Click the "Install" icon in the address bar or select "Install AR Master" from the Chrome menu.
3. **Mobile**: Use "Add to Home Screen" from your browser menu.

1. 프로젝트 웹사이트에 접속하세요: [https://idpw1408-code.github.io/AR_Master/](https://idpw1408-code.github.io/AR_Master/)
2. **데스크톱**: 주소창의 '설치' 아이콘을 클릭하거나 크롬 메뉴에서 'AR Master 설치'를 선택하세요.
3. **모바일**: 브라우저 메뉴에서 '홈 화면에 추가'를 선택하세요.
